# Getting help

- **How do I…?** Start with the [guides](docs/guides/README.md), then ask in [Discussions](https://github.com/Shades-Media-Group/PageRecast/discussions).
- **A page didn't import well:** open an [import report](https://github.com/Shades-Media-Group/PageRecast/issues/new?template=import.yml).
- **Something is broken:** open a [bug report](https://github.com/Shades-Media-Group/PageRecast/issues/new?template=bug.yml).
- **A security issue:** follow [SECURITY.md](SECURITY.md).

PageRecast is free and maintained by [Shades Media Group](https://shades.md). Answers come from the maintainers and the community, usually within a few days.
